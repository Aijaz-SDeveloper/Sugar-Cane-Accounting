# Sugar-Cane-Accounting
Managed and developed Sugar Industry modules including Token Management, Weighbridge, Sugarcane Payment, Cane Analysis, and Production Monitoring. Automated payment calculations,
ensured accurate weight capture, developed reports, and optimized workflows for improved operational efficiency.
